# 🏦 HDFC Mutual Fund FAQ Chatbot

🚀 **Live App:** https://hdfc-faq-bot.streamlit.app/

This is a RAG-based chatbot that answers HDFC Mutual Fund FAQs.

**Scope:** HDFC AMC - 5 schemes (Large, Flexi, ELSS, Mid, Small Cap Direct Growth)

**Features:** Facts-only, 1 citation per answer, Last updated tag, PII guardrail, No advice

**Try:**
- What is ELSS lock-in?
- What is Small Cap exit load?
- Minimum SIP for Flexi Cap?
